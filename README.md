# Smart Hostel AI – Multimodal Hostel Maintenance Management SaaS

An independently developed product focused on transforming hostel maintenance through centralized workflows, multimodal AI and intelligent maintenance operations.

## Vision

Smart Hostel aims to go beyond conventional complaint management by combining a structured maintenance lifecycle with AI-powered understanding of text and visual complaint evidence.

## Four Role-Based Portals

* **Student:** Submit complaints with descriptions and photographs, track progress and verify resolutions.
* **Technician:** Manage assigned jobs, document repair work and upload completion evidence.
* **Warden:** Monitor hostel operations, assign technicians, manage priorities and track SLA breaches.
* **Admin:** Manage institutions, users, hostel infrastructure and maintenance analytics.

## Planned Multimodal AI Capabilities

* Image-based maintenance issue recognition.
* Natural-language complaint understanding.
* AI-assisted complaint categorization.
* Severity and priority recommendations.
* Potential emergency risk identification.
* Intelligent technician assignment recommendations.
* Predictive maintenance using historical failure data.

## Technology Stack

**Frontend:** React, Vite, Tailwind CSS, JavaScript.

**Backend:** Python, FastAPI, SQLAlchemy.

**Database:** SQLite for local development; PostgreSQL planned for production.

**Architecture:** REST APIs, JWT authentication and role-based authorization.

## Core Workflow

Report → Understand → Confirm → Assign → Acknowledge → Resolve → Verify → Close / Reopen.
